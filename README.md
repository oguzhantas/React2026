### Kurulum

1) NodeJS indir ve kur
   
3) Android Studio indir kur, Emülatör ekle
   
3) VS Code indir kur, React eklentisi ekle

4) React_Projeleri klasörü oluştur.

5) VS Code'dan File-Open Folder React Projeleri klasörünü seç

6) VS Code'da Terminal- New Terminal ile yeni konsol aç

7) "npx create-expo-app projem" yaz

8) "cd projem" ile proje klaösrüne gir.

9) "npm run web" yaz ve tarayıcı üzerinde çalıştır.

10) Android Studio'da emülatör açıksa "npm run android" yaz emülatörde çalıştır.
